# About VODTV
VODTV is a modern self‑hosted media documentation & playback application built for private media viewing scenarios.

## Design Philosophy
We believe a great media system should balance ease‑of‑use, privacy and feature richness. VODTV is committed to delivering:
- **Privacy‑First** — Keep your media data under your own control
- **Feature‑Rich** — Cover media browsing, searching, AI assistant and multi‑source playback
- **Easy Deployment** — Simple configuration, run with Docker in minutes
- **Highly Customizable** — Flexible settings to fit your personal usage

## Key Features
### 🎨 Modern UI
- Clean modern interface
- Light / dark theme support
- Fully responsive layout for PC, tablet and mobile devices

### 🚀 Powerful Media Capabilities
- Multi‑source VOD resource integration
- Custom media category based on Douban search
- Live‑stream source management
- Built‑in AI recommendation & Q&A assistant
- Cloud‑disk resource search
- TVBox compatible API

### ⚡ Great Performance
- Built on Next.js
- Efficient interface caching
- Optimized page rendering
- Support Redis / Kvrocks / Upstash storage backend

### 🔧 Easy to Extend & Deploy
- Docker one‑click deployment
- Web‑based admin dashboard, no manual file editing required
- Import & export full configuration for backup and migration
- Plugin‑friendly architecture

## Development Team
VODTV is developed and maintained by the open‑source community team. We focus on personal self‑hosted media solutions, aiming to build a convenient private media service for enthusiasts.

## Tech Stack
- **Next.js** — Full‑stack React web framework
- **Vue 3** — Front‑end component library
- **VitePress** — Static documentation site generator
- **TypeScript** — Type‑safe development
- **Tailwind CSS** — Atomic CSS styling
- **Redis / Kvrocks** — Cache and metadata storage
